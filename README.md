# Sistema de Registro Pedagógico com IA

Sistema web desenvolvido para auxiliar professoras no registro e acompanhamento do comportamento e desenvolvimento dos alunos através de inteligência artificial.

## Objetivo

Permitir que professoras registrem observações pedagógicas através de áudios enviados no sistema. Os áudios serão processados por inteligência artificial para gerar transcrição, organização e resumos automáticos.

## Funcionalidades (PoC)

- Envio de áudio pelas professoras
- Transcrição automática
- Organização das observações por aluno
- Geração de resumos automáticos
- Histórico de observações

## Arquitetura

O sistema será desenvolvido utilizando arquitetura baseada em microserviços para permitir escalabilidade e futura expansão para outras instituições de ensino.

## Tecnologias

- Python
- APIs de Inteligência Artificial
- Banco de Dados
- Arquitetura de Microserviços
